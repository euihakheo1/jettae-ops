# 결제·주문 장애 대응

작성: 결제팀, 주문팀
최종 편집: 2026년 3월 12일
태그: 장애대응, 결제, 주문, 환율, 이메일

> 별빛상점 주문 흐름(장바구니 → 주문 → 결제)에서 장애가 났을 때 먼저 보는 문서입니다.
> 대시보드: Grafana › 별빛상점 › 주문·결제

## 결제 서비스 (payment)

결제 실패율 알람(5% 초과 3분 지속)이 오면 결제 장애로 본다.
결제 장애가 계속되면 김대리에게 연락, 안 되면 롤백.

## 주문/체크아웃 (checkout)

- 감지: 주문 실패율 알람 → 정민혁 과장 호출
- 담당: 정민혁 과장 (슬랙, 전화)
- 상향: 정민혁 과장 15분 미응답 시 최영훈 차장에게 상향
- 롤백: 한서윤 CTO 승인 후 정민혁 과장이 실행

### 최영훈 차장

- 주문 장애 상향을 받으면 정민혁 과장과 같이 원인 확인
- 최영훈 차장 20분 미응답 시 정민혁 과장에게 다시 연락

## 환율 (currency)

- 감지: 환율 변환 오류율 알람 → 강현우 사원 호출
- 담당: 강현우 사원 (슬랙, 전화)
- 상향: 강현우 사원 10분 미응답 시 박재현 팀장에게 전화로 상향
- 롤백: 박재현 팀장 승인 후 강현우 사원이 실행

## 이메일 (email)

- 감지: 주문 확인 메일 발송 실패 알람 → 이수진 대리 호출
- 담당: 이수진 대리 (사내 메신저, 전화)
- 상향: 이수진 대리 10분 미응답 시 박재현 팀장에게 상향
- 조치: 메모리 누수(emailMemoryLeak) 의심 시 재시작 — 박재현 팀장 승인 후 이수진 대리가 실행
