# 쇼핑 화면 장애 대응 (장바구니·상품 카탈로그)

작성: 개발팀
최종 편집: 2026년 5월 20일
태그: 장애대응, 장바구니, 카탈로그, 프론트엔드

## 장바구니 (cart)

| 항목 | 내용 |
|---|---|
| 담당 | 이수진 대리 |
| 연락 | 사내 메신저(1순위) → 안 되면 전화 |
| 감지 | cartFailure 오류율 알람 (장바구니 API 오류율 2% 초과 5분 지속) |
| 상향 | 10분 미응답 시 박재현 팀장 상향 |
| 롤백 승인 | 박재현 팀장 |
| 롤백 실행 | 이수진 대리 |
| 대시보드 | Grafana › 별빛상점 › 장바구니 |

## 웹 프론트엔드 (frontend)

| 항목 | 내용 |
|---|---|
| 담당 | 이수진 대리 |
| 연락 | 사내 메신저(1순위) → 안 되면 전화 |

| 롤백 승인 | 박재현 팀장 |
| 롤백 실행 | 이수진 대리 |

## 추천 (recommendation)

- 감지: 추천 API 오류율 알람 → 강현우 사원 호출
- 담당: 강현우 사원 (슬랙, 전화)
- 상향: 강현우 사원 10분 미응답 시 박재현 팀장에게 전화로 상향
- 조치: 추천 캐시 장애(recommendationCacheFailure)면 기능 플래그 끄기 — 박재현 팀장 승인 후 강현우 사원이 실행

## 광고 (ad)

- 감지: 광고 API 오류율 알람 → 강현우 사원 호출
- 담당: 강현우 사원 (슬랙, 전화)
- 상향: 강현우 사원 10분 미응답 시 박재현 팀장에게 전화로 상향
- 조치: 광고 장애(adFailure, adHighCpu)면 기능 플래그 끄기 — 박재현 팀장 승인 후 강현우 사원이 실행
