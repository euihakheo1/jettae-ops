# ADR-0003: 그래프는 불변 값, 변경은 승인된 패치 이벤트

- 상태: 채택 (2026-10-13)

## 맥락
런북 지식은 "누가 언제 무엇을 왜 바꿨는가"가 남아야 증적이 된다. 기억에 의존하던 판단을 자산으로 바꾸려면
변경 이력이 추적 가능하고 되돌릴 수 있어야 한다.

## 결정
- `OpsGraph`는 불변(frozen) 값 객체이고, `content_hash()`(canonical JSON의 SHA-256)로 식별한다.
- 그래프를 바꾸는 유일한 경로는 `Patch`다. 흐름은 초안(AI 또는 템플릿) → `validate_patch`(재검사, 과거 리허설 무회귀,
  명부 외 인물 0) → 팀 리드 승인 → `GraphVersion` 추가 순이다.
- 되돌리기도 새 버전이다(`revert_of`). 이력을 지우지 않는다(append-only).
- 저장소는 낙관적 동시성을 쓴다. 기준 버전이 head가 아니면 `VersionConflictError`를 낸다.
- 모델 재학습은 없다. 사람의 수정은 그래프에 출처(`SourceKind.PATCH`, 패치 ID)와 함께 남는다.

## 결과
- 증적 리포트에 개정 이력(누가, 언제, 어떤 끊김을, 어떤 리허설로 검증해 승인했는지)이 자동으로 들어간다.
- 같은 버전에서 같은 리허설을 다시 돌리면 결과 해시가 같다.
