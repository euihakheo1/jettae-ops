# ADR-0002: 원문 근거 정렬과 "없음은 없음"

- 상태: 채택 (2026-10-13)

## 맥락
LLM 추출의 가장 위험한 실패는 **결측 환각**이다. 런북에 승인자가 없는데 "보통 팀장이 승인하니까" 승인자를 채워 넣으면,
제때옵스가 찾아야 할 끊김이 오히려 가려진다.

## 결정
- 모든 추출기(규칙·LLM)는 공통 IR(`domain.extraction`)로 **원문을 그대로 옮긴 인용(quote)**을 낸다.
- `extract.align`이 인용을 원문 문자 위치에 정렬한다. 순서는 정확 일치 → 공백 정규화 → 퍼지(partial ratio ≥ 90)다.
  정렬에 실패한 요소는 **폐기**하고 `GroundingStatus.dropped_ungrounded`에 집계한다. 이 방식은 Google LangExtract의
  source grounding을 따른다.
- `Provenance(source=RUNBOOK)`는 span이 없으면 생성 자체가 거부된다(도메인 검증기).
- 명부·카탈로그에서 온 사실은 `ROSTER`/`CATALOG` 출처로 따로 표시하고, 런북 출처와 섞지 않는다.
- 역번역 대조(`extract.backtranslate`): 그래프 요소를 한국어 문장으로 되돌려 원문과 숫자·인물·채널·부정어 슬롯을 비교한다.
  불일치하면 `Verification.HOLD`(판단 보류)로 둔다. 판단 보류 요소는 점수에서 통과로 계산하지 않는다(확인 불가 ≠ 정상).

## 결과
- KPI "원문 근거 위치 없는 필드 0건"이 구조적으로 보장된다.
- 평가에서 "지운 필드를 AI가 지어낸 비율(결측 환각률)"을 직접 측정할 수 있다.
