# 실데이터 실증 공개 파일

해석과 한계는 [../realdata-results.md](../realdata-results.md)에 있다. 이 폴더의 `*-metrics.json`·`*-report.md`는 평가 도구가
쓴 원본을 그대로 옮긴 것이다. `retro-report.md`에만 맨 위에 주의 문구 한 줄을 덧붙였다.

- `gitlab-test-*` — 실증 ① GitLab 공개 런북 test 20건. 보고서가 가리키는 `results.jsonl`·`review.csv`는 이 폴더에 없다
  (사람 검토 표본은 2026-10-22 검토 전까지 블라인드로 둔다).
- `gitlab-test-ko-*` — 실증 ① 언어 대조: 같은 test 20건의 한국어 번역판을 같은 설정으로 돌린 결과. 두 코더 일치 정밀도
  71.8%(28/39)로 원문 68.6%와 같은 수준이고, 문서별 지적은 원문과 33건만 같다(원문 59 · 번역판 45). 보고서의 '원자료' 줄은
  번역의 원문 저장소를 가리킨다. '한계' 절 첫 줄('영어 문서')은 도구가 늘 쓰는 고정 문구라 이 실행에는 맞지 않는다 — 입력은
  한국어 번역판이고, 제품이 한국어가 아닌 문서로 분류한 2건(코드 비중이 큰 문서)만 역번역 LLM 대조를 건너뛰었다.
  보고서의 '사람 검토 표본' 절도 도구가 늘 쓰는 안내일 뿐이고, 번역판 지적 45건은 2026-10-22 사람 검토 대상이 아니다.
  `results.jsonl`·`review.*`는 이 폴더에 없다.
- `gitlab-runbooks-ko/` — test 20건의 한국어 충실 번역판. 원문과 줄 번호가 같다. GitLab 런북(MIT, 고정 커밋
  `844a2b882687492cf117cc2fc553f7fbf9a02197`)의 2차 저작물로, 출처는 GitLab, Inc.이고 원문 라이선스는 `LICENSE`에 그대로 두었다.
  번역 방법·검사·남은 경고와 원문/번역 해시는 `SOURCE.md`에 있다. 번역판 안의 문서 내 앵커 링크 12개는 제목을 번역해서
  맞지 않는다(`SOURCE.md` 참고).
- `retro-*` — 실증 ② 공개 사후 보고서 27건. `retro-report.md`의 m/k 80.5%는 느슨한 계열·요소 일치다. 제품이 진단한 24건만
  보면 82.5%(33/40)이고, 다른 사고의 지적과 대조한 우연 기준선 82.2%(`retro-baseline.txt` 2절)와 같아 **사고별 사전 탐지의
  근거가 아니다.** 진단하지 않은 3건(복원 묶음에 런북 없음)까지 넣은 기준선 73.1%(2-1절)는 아래로 치우친 값이라 80.5%와
  견주지 않는다.
- `retro-incidents.csv` — 사고별 수치·원 제목·출처 주소만 담았다. 보고서 본문, 인용, 재구성 묶음 글은 넣지 않았다.
- `retro-baseline.txt` — `python -I scripts/realdata_retro_baseline.py <retro results.jsonl>`의 출력.
